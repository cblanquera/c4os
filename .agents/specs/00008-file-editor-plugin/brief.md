# File Editor Plugin Brief

Status: Proposed

## Goal

Define trusted-root file browsing and editing, UI-owned editor state, backend-owned file authority, platform-aware file operations, context menus, icons, trash/recycle behavior, and typed editor events.

## Boundaries

- Planning only; no implementation is authorized.
- File authority and trust enforcement remain backend-owned.
- Shared truth comes from Context Files, not sibling specs.
