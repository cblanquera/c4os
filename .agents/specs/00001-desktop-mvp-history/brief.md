# Desktop MVP Historical Brief

Status: Frozen

The desktop MVP established the accepted production baseline under root `backend/`, `frontend/`, and `tests/server/`. It covered the C4OS desktop shell, sessions, providers, files, artifacts, Browser, Terminal, extensions, concurrency, persistence, local memory, approvals, security, runtime-tool events, and release-readiness integration through legacy TASK-017.

This package is historical. It does not authorize new implementation or replace the current proposed plugin-first final-implementation specs.
