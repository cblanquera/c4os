# Browser Plugin Brief

Status: Proposed

## Goal

Define user-owned Browser navigation and actions, screenshots, annotation attachment bundles, project-scoped profiles, local-file behavior, request-scoped agent browsing, shared app-owned hydration state, and document-family preview boundaries.

## Boundaries

- Planning only; no implementation is authorized.
- Browser views must not expose privileged bridges to untrusted content.
- Shared truth comes from Context Files, not sibling specs.
