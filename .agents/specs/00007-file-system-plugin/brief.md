# File System Plugin Brief

Status: Proposed

## Goal

Define project-folder identity, workspace-file grouping, user-level registry and chats, missing-path handling, relocation, search, clone, remove, non-Git support, and filesystem platform boundaries.

## Boundaries

- Planning only; no implementation is authorized.
- Trusted-folder enforcement remains backend-owned.
- Shared truth comes from Context Files, not sibling specs.
