# Chat Prompt Interactions Brief

Status: Proposed

## Goal

Define backend-authoritative prompt-tag resolution, branch selection, attachments and references, approval events and remembered rules, model capability handling, and provider-safe degradation.

## Boundaries

- Planning only; no implementation is authorized.
- Prompt parsing must not become a frontend security or tool-execution authority.
- Shared truth comes from Context Files, not sibling specs.
