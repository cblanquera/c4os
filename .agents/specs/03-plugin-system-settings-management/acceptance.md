# Plugin System And Settings Management Acceptance

Status: proposed

| ID | Acceptance Criteria |
| --- | --- |
| AC-001 | Settings > Plugins can show enabled, disabled, dependency-blocked, incompatible, and repairable states. |
| AC-002 | Plugin settings schema can render text, textarea, switch, number input, and select fields. |
| AC-003 | Lifecycle changes are live for UI/settings and restart-gated for native backend registration. |
| AC-004 | Uninstall prompts whether to delete plugin-owned user data. |
