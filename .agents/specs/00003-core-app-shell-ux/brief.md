# Core App Shell UX Brief

Status: Proposed

## Goal

Define the final persistent shell layout, optional left and right plugin panels, center-pane minimum, Settings route behavior, per-chat visibility restoration, and plugin icon placement and reordering.

## Boundaries

- Planning only; no implementation is authorized.
- UI behavior must remain consistent with accepted creative context and reviewed wireframes.
- Shared truth comes from Context Files, not sibling specs.
