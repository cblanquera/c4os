# Plugin System And Settings Management Brief

Status: Proposed

## Goal

Define Codex-compatible plugin discovery, `plugin.json`, C4OS `agents/c4os.yaml` metadata, settings schemas, sensitive configuration, dependencies, icons, marketplace sources, install state, enablement, repair, and migration lifecycle.

## Boundaries

- Planning only; no implementation is authorized.
- C4OS app plugins remain distinct from Tauri plugins.
- Shared truth comes from Context Files, not sibling specs.
