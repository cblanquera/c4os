# Skills Settings Brief

Status: Proposed

## Goal

Define bundled, user-global, plugin-provided, and project-local skill discovery; source precedence; metadata-first scanning; customization copies; invalid and disabled states; repair; and `$` suggestion eligibility.

## Boundaries

- Planning only; no implementation is authorized.
- Invalid or disabled skills must not affect runtime context.
- Shared truth comes from Context Files, not sibling specs.
