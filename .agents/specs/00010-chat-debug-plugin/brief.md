# Chat Debug Plugin Brief

Status: Proposed

## Goal

Define a developer-oriented per-chat debug view for typed runtime and tool events, CLI activity, approval visibility, redaction-before-persistence, bounded history, diagnostic language, and no export.

## Boundaries

- Planning only; no implementation is authorized.
- Chat Debug observes C4OS-owned records and does not become execution authority.
- Shared truth comes from Context Files, not sibling specs.
