# File Editor Plugin Acceptance

Status: proposed

| ID | Acceptance Criteria |
| --- | --- |
| AC-001 | IDE cannot enable without FS dependency. |
| AC-002 | File references inserted from explorer match manual @ file tag behavior. |
| AC-003 | External file changes require user choice before overwrite. |
| AC-004 | The spec identifies the backend file service/policy path for each read, write, create, rename, delete, save, and revert operation. |
| AC-005 | Delete behavior documents OS trash/recycle path, fallback, and Windows validation provision. |
| AC-006 | Editor state events are defined for Chat Debug, prompt attachment/reference handling, and plugin hydration without UI text scraping. |
| AC-007 | Editor labels and empty states do not assume the opened folder is a code repository. |
